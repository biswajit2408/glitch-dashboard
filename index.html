Why JSONBin.io?
JSONBin stores your data as JSON online. It has full CORS support — works from GitHub Pages, localhost, anywhere. Free tier gives you 10,000 requests/month which is more than enough for personal use. No server needed.
📋 Setup steps — 3 minutes
1
Go to jsonbin.io → click Sign Up → create free account with your Gmail
2
After login → click your profile icon (top right) → API Keys → copy the Secret Key (starts with $2b$...)
3
Paste the key below → click Connect & Initialize — this creates your database automatically
